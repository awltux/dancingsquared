# Course overview

The CALLERLAB (New) Mainstream Suggested Teaching Order lists **50 units** (`M1` … `M50`), effective
1 September 2026. It is a *sequence*, not a syllabus of lessons: each unit assumes only what came
before it.

This book keeps the official order and divides it into **twelve classes** of four or five units, which
is roughly a term of weekly evenings. The grouping is this book's, not CALLERLAB's — the order within
it is CALLERLAB's, and is not changed.

## How to use a class page

Each class page gives you:

- **the units** for that class, with links to their call pages;
- **what to assume** — the units it builds on;
- **a teaching sequence**, so you can walk the calls through before dancing them;
- **drills** that put the new calls into a short piece of real dancing;
- **checks** — the mistakes that mean the class has not landed yet.

The class page does **not** explain the calls. That is what the call pages are for, and explaining
them twice is how a book starts disagreeing with itself.

## If you are learning at home

You can follow the same order without a class:

1. Read the [call pages](../04-calls/m01-circle-family.md) for one class, one unit at a time.
2. Walk each call slowly on your own — the **What you do** section is written to be walked.
3. Use the **figures** to check the start and end shapes.
4. Watch for the **common faults**; they are the ones that catch everybody.
5. Move on when you can do the call without reading it.

Two calls per evening is a comfortable pace.

## How much is 50 calls?

Enough to dance a whole evening. The 2026 program is deliberately smaller than the old Basic +
Mainstream combination it replaces, which is why some calls you may have known are no longer here —
see [Moved and renamed](../08-reference/moved-and-renamed.md).

The teaching order puts the calls you will use constantly first, and the ones that only appear in
particular figures later. By the end of Class 5 you can already dance a recognisable tip.
