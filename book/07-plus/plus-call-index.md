# Plus call index

Every call in the CALLERLAB *Plus Program Definitions*, revised **25 August 2026**, in the order the
manual prints them. This is an index, not a course: [where Mainstream leads](where-mainstream-leads.md)
explains what Plus changes, and the definitions themselves are CALLERLAB's.

| Call | What it is |
|---|---|
| **(anything) and Roll** | do the named call, then Roll — a wrapper with a slot in it |
| **(anything) and Spread** | do the named call, then Spread — a wrapper |
| **Acey Deucey** | a circulate in which the ends and centres swap by pulling past each other |
| **All 8 Spin the Top** | Spin the Top, danced by all eight from a wave |
| **Chase Right** | from a right-hand two-faced line, the dancers chase and turn as a unit |
| **Circle to a Line** | from a circle, break it into a line |
| **Clover and (anything)** | the Cloverleaf shape with a named call worked in |
| **Cloverleaf** | four dancers separate and loop, leaving in a line |
| **Coordinate** | a four-dancer call that puts the centres and ends together in a line |
| **Crossfire** | a circulate-and-cross figure |
| **Cut the Diamond** | the diamond's own call, cutting it in two |
| **Diamond Circulate** | a circulate around a diamond formation |
| **Dixie Grand** | a grand-square-shaped figure that ends with a swing |
| **Dixie Style to an Ocean Wave** | the Dixie Style figure flowing into a wave |
| **Do Paso** | an allemande figure — partner left, corner right, partner left, then turn |
| **Eight Chain Thru** | facing couples chain round the square, passing through |
| **Explode and (anything)** | everyone explodes outward, then does the named call |

## Names that will look familiar

Several Plus calls are named after Mainstream families you already know: **Circulate**
([M19](../04-calls/m19-circulate-family.md)), **Trade** ([M32](../04-calls/m32-trade-family.md)),
**Hinge** ([M43](../04-calls/m43-hinge-family.md)), **Tag** ([M49](../04-calls/m49-tag-the-line-family.md))
and **Fold** ([M48](../04-calls/m48-fold-cross-fold.md)). That is not a coincidence: Plus extends
families rather than inventing new ideas.
