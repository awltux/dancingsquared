# Index — the map of this book

## Three ways to read it

**If you have never danced** — go straight through, in order:
[What square dancing is](01-start/what-is-square-dancing.md) →
[The square](01-start/the-square.md) →
[Your first call](01-start/your-first-call.md) →
[Naming the dancers](02-language/naming-the-dancers.md) →
then the classes in [05-course](05-course/course-overview.md), using [04-calls](04-calls/m01-circle-family.md) as the reference beside you.

**If you are learning a specific call** — jump to it in [the call index](08-reference/call-index.md).
Every call page is self-contained: it links to the words it uses rather than re-explaining them.

**If you are teaching** — read [the course](05-course/course-overview.md) and
[teaching a class](05-course/teaching-a-class.md), and take the drills from
[drills](06-practice/drills.md).
